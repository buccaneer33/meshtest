# MESHTEST TEST

Проект основан на [Angular CLI](https://github.com/angular/angular-cli) version 20.1.5.

## Development server

Что бы запустить проект наберите в консоли:

```bash
ng start
```

И перейдите на ```http:\\localhost: 4200``` после чего роутинг сам вынесет.

В проекте реализованы таблица с данными и отсроченным рендером для облегчения отрисовки, реализована реактивная форма для КРУД со встроенной валидацией, хорошие нормальные самописные правила с которыми работал долгое время увы вытащить не удалось.

Использован бутстрап 4.

Реализован интерсептор для вывода в консоль данных.

NgRX не использовался потому что он затребует массу времени на написания бойлерплейта с нуля а рабочего вариант под рукой нет.

На проекте использовался стайл-гайд и основа из одного прошлого проекта.
